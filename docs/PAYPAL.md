# 支付寶 AI 付收款（Vibe Pay 賽道）— 建立中

## 產品定價
**¥0.01 買斷**（一次付費，永久使用）。金額由伺服器固定，前端與桌面應用不接受客戶端傳入的金額。

## 收款流程
1. 使用者在官網點擊「支付寶 AI 付 ¥0.01 購買」
2. 伺服器建立訂單，金額固定為 ¥0.01 人民幣
3. 使用者掃碼付款，伺服器收到非同步通知並驗簽後簽發授權碼
4. 使用者將授權碼貼回桌面應用，離線驗證後啟用

## 密鑰管理（鐵律）
- AppID、私鑰、支付寶公鑰 **絕對不進倉庫、不進前端、不進桌面程式**
- 僅存在伺服端環境變數 / Cloudflare Secret
- 倉庫只放 `.env.example`
